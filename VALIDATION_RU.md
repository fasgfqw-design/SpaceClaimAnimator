# Проверка SC Animator v1.8.17 — 28.09.2026

Проверьте на модели с несколькими предложениями: наведение на каждый зелёный маркер должно подсвечивать две цилиндрические грани разными цветами и ни при каких условиях не добавлять Align. Отдельный щелчок ЛКМ должен создать только наведённый Align. Выбор строки списка без двойного щелчка только показывает соответствующую пару; двойной щелчок создаёт Align. Если в строке состояния написано `Native face highlight fallback`, сетка граней недоступна и SpaceClaim показывает штатную одноцветную подсветку — сообщите об этом вместе с моделью для дальнейшей диагностики.

При выборе предложения с включённым `Isolate selected pair` все остальные тела должны скрыться; выбор другой строки должен показать новую пару. Выключение галочки и закрытие окна должны вернуть исходную видимость, включая тела, которые были скрыты ещё до открытия Mechanisms. Проверьте иерархические компоненты и повторяющиеся экземпляры одной детали. Перед созданием Align исходная видимость должна восстановиться. Режим использует write block SpaceClaim; проверьте Undo после просмотра.

Для шести предложений наведите курсор на край каждого круга, не только на его центр. В каждой точке должен подсвечиваться именно соответствующий этому кругу кандидат, включая ранее перекрытые маркеры. Щёлкните по второму или третьему маркеру: должен создаться Align именно для показанной при наведении пары. Убедитесь, что подсвечены поверхности обеих цилиндрических граней, а не одни рёбра. Закройте окно и проверьте, что предыдущая вторичная подсветка SpaceClaim восстановилась.

На копии модели с шестью предложениями, из которых раньше были видны только три маркера, откройте Mechanisms: все шесть должны стать отдельными маркерами. Поочерёдно наведите курсор на каждый: должны подсвечиваться именно две цилиндрические поверхности, синий fixed и оранжевый moving, а не одни рёбра. Поверните и приблизьте модель, повторите наведение и выбор всех шести. Контуры допустимы только как дополнительная подсказка или запасной вариант, если SpaceClaim не предоставляет сетку конкретной грани.

Наведите курсор на каждый зелёный маркер: контур неподвижной цилиндрической грани должен стать синим, движущейся — оранжевым; строка статуса должна назвать оба компонента. Уберите курсор — подсветка должна исчезнуть. Нажмите маркер и удалите созданный шарнир кнопкой Remove joint: принадлежащий ему штатный Align должен исчезнуть, а ранее записанные ключи остаться. Повторите после Save → Close → Open. Отдельно проверьте повторное использование существующего Align: Remove joint должен сохранить его. При дублировании анимации удаление шарнира в одной копии должно оставить общий Align, а удаление последней ссылки — удалить. Старые шарниры v1.8.4 без сохранённой связи с Align не должны удалять существующие условия сборки.

Кинематика в SpaceClaim. На копии модели выделите две детали с соосными цилиндрическими поверхностями и откройте **Mechanisms**. Все предложения должны быть видны как крупные зелёные маркеры, даже если слабые контуры граней не заметны. Щёлкните один маркер: в дереве SpaceClaim должен появиться штатный Align между правильными гранями, а движущаяся деталь должна получить стартовую дорожку SC Animator. Вращение камеры не должно оставлять следов маркеров; закрытие окна удаляет все подсказки. Проверьте создание через выбор строки и **Create Align**, повторное открытие окна без дублирования связи и **✓ Add all** для нескольких однозначных пар. Отмените создание обычным Undo SpaceClaim, затем проверьте сохранение и повторное открытие модели. В частности проверьте, что созданный Align оставляет разрешённым вращение вокруг оси. После Move на 90° добавьте ключ в Tracks и проверьте крайние положения, Play и экспорт. **Remove joint** должен удалить созданный аддоном Align и оставить записанные ключи. Повторите с активными сторонними Align/Tangent и другим центром оси. Это обязательный интерактивный тест: консоль не запускает сборочный решатель или выбор маркеров в SpaceClaim.


Проверка API V261: `DatumPlane.Transform(Matrix)` перемещает обычную Plane; `InteractionContext.SectionPlane` доступна только для чтения. Поэтому аддон записывает выбранную свободную DatumPlane и перемещает её. Режим Clipping включается вручную в SpaceClaim. У `Component` нет прямого свойства видимости или числовой прозрачности экземпляра. Для одиночной детали Show/Hide применяются к `IDesignBody` в сцене. Fade использует `AppearanceHelper.SetColor` из установленной интерфейсной сборки V261 для изменения альфа-канала цвета мастер-тела и временно ставит `BodyStyle.Default`; исходные цвет и стиль затем восстанавливаются. Публичный `Body.SetColor` игнорирует альфа-канал, поэтому при ошибке прямого пути используется прежнее RGB-приближение. Грани с собственными цветами могут не подчиняться цвету тела. Дубликаты детали и вложенные сборки исключены. Реальный визуальный результат и связь Clipping с положением/видимостью Plane консольная проверка не подтверждает.

В поле Find введите часть имени компонента и затем диаметр: список и видимые шарики должны показывать только совпадения. Очистка поля возвращает остальные предложения. Add all с активным фильтром должен работать только по видимым строкам; при уже связанном движущемся компоненте добавляйте дополнительные шарниры вручную.

Проверка v1.8.15: на копии модели с двумя почти параллельными цилиндрическими осями, смещёнными примерно на 0,8 мм, задайте Max offset 0,5 мм — предложение не должно появиться. Поставьте 1 мм — строка с фактическим offset и шарик должны появиться. Выберите предложение и создайте Align; SpaceClaim должен либо применить его, либо выдать понятную ошибку при конфликте сборочных условий. Проверьте, что два разных близких шарнира не сливаются в одно предложение при увеличении допуска.

Проверка v1.8.16: в Mechanisms задайте Ø from 10 мм и Ø to 20 мм. Должны остаться только предложения с указанным включительным диаметром; шарики других пар должны скрыться. Дополнительно введите часть имени компонента в Find, затем очистите текст и диапазон — список должен восстановиться. Если from больше to, предложения скрываются и появляется сообщение о пустом диапазоне. После Swap fixed/moving отображаемый диаметр и результат фильтра должны соответствовать новой неподвижной грани.

Проверка v1.8.17: откройте Mechanisms на модели с одиночными и сгруппированными предложениями, затем нажмите Find axes несколько раз. Каждый шарик должен быть виден зелёным сразу после поиска, до наведения мыши; наведение лишь меняет его цвет. Повторите с активными текстовым и диаметральным фильтрами и после поворота камеры.
